# Cartel INHALEX imprimible

Archivo principal:

- `index.html`

## Como verlo

Abre `index.html` en Chrome o Edge.

## Como exportarlo a PDF

1. Presiona `Ctrl + P`.
2. Destino: `Guardar como PDF`.
3. Margenes: `Ninguno`.
4. Escala: `100%`.
5. Activa `Graficos de fondo`.
6. Si aparece la opcion, usa el tamano definido por CSS.
7. Si tu navegador no respeta el CSS, crea tamano personalizado:
   - Ancho: `80 cm`
   - Alto: `180 cm`
