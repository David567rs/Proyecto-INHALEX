# Cartel INHALEX - Encuentro Universitario Empresarial TI 2026

Formato recomendado para Canva: **80 cm de ancho x 180 cm de alto**.

## Concepto visual

**Idea central:** presentar INHALEX como una solucion profesional de software que conecta la universidad con una empresa real, digitalizando catalogo, pedidos, inventario, ventas, reportes y experiencia del cliente.

**Frase guia:**  
**Creamos soluciones, no solo sistemas.**

**Estilo:** limpio, institucional, natural y tecnologico. Usar fondo claro, verdes de marca, acentos azules institucionales y detalles dorado suave.

### 4. Problema y solucion - 58 a 90 cm

Dividir en dos columnas.

**Problema detectado**

INHALEX necesitaba centralizar la gestion de su catalogo, pedidos, inventario y seguimiento al cliente. La administracion manual dificultaba conocer existencias reales, atender reportes, publicar promociones y dar una experiencia digital clara a los usuarios.

**Solucion implementada**

Se desarrollo una plataforma web full stack con catalogo publico, bolsa de compras, cuenta de cliente, reseñas, favoritos, avisos, reportes e interfaz administrativa para gestionar productos, inventario, pedidos, ventas, promociones y contenido institucional.

### 5. Stack tecnologico - 90 a 112 cm

**Frontend**

Next.js 16 · React 19 · TypeScript · Tailwind CSS · shadcn/ui · Radix UI · Lucide Icons

**Backend**

NestJS · Node.js · TypeScript · JWT · Passport · Class Validator · Mongoose

**Base de datos y servicios**

MongoDB · Cloudinary · Vercel Analytics · Arquitectura modular por dominios

**Modulos principales**

Catalogo · Inventario · Pedidos · Clientes · Reseñas · Notificaciones · Reportes · Promociones · Ventas · Respaldos

### 6. Resultados y beneficios - 112 a 135 cm

Usar 4 indicadores o bullets grandes.

**Beneficios para la empresa**

- Catalogo digital organizado por lineas y aromas.
- Control de inventario con existencias, reservas y productos bajo pedido.
- Confirmacion de pedidos con validacion previa de disponibilidad.
- Panel administrativo para ventas, reportes, productos y contenido.
- Historial de avisos, reseñas y seguimiento para clientes.
- Mejor presencia digital y experiencia profesional de compra.

**Resultado clave**

La empresa obtiene una herramienta centralizada para operar mejor, reducir desorden administrativo y ofrecer una experiencia mas clara a sus clientes.

## Recomendaciones en Canva

1. Crear diseno personalizado: **80 cm x 180 cm**.
2. Activar reglas y guias.
3. Dejar margen seguro de **3 cm**.
4. Usar bloques verticales con separadores suaves.
5. Evitar parrafos largos: maximo 3 a 4 lineas por bloque.
6. Exportar como **PDF para impresion**.
7. Si la imprenta lo pide, activar marcas de corte y sangrado.
8. Usar imagenes y capturas en buena resolucion.
